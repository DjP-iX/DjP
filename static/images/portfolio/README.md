# Portfolio Images

This directory contains images for portfolio projects. Extract these from your danielpizappi.com website.

## Directory Structure

- **web-design/** - Screenshots of web projects (EMR Society, Cooking Up a Movement, etc.)
- **graphic-design/** - Posters, book covers, album covers, data visualizations
- **instructional/** - Course material thumbnails and instructional design samples

## Image Guidelines

1. **File Naming**: Use descriptive filenames with hyphens:
   - `emr-society-redesign-before.jpg`
   - `emr-society-redesign-after.jpg`
   - `cooking-up-movement-screenshot.jpg`
   - `nexus-logo-redesign.png`

2. **Optimization**:
   - Max width: 1200px for full-width images
   - Compress to web-appropriate file sizes
   - Convert to WebP where possible for better performance
   - Use descriptive alt text in markdown

3. **Usage in Content**:
   ```markdown
   ![Alt text description](/images/portfolio/web-design/filename.jpg)
   ```
